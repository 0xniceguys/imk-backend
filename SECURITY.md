# Security Policy

## Supported Versions

Security fixes are best-effort for:

- the current `main` branch
- the latest published release

Older tags and stale feature branches may not receive fixes.

## Reporting a Vulnerability

Do not open a public GitHub issue for a security vulnerability.

Instead:

1. Email `shreyaan.work@gmail.com`
2. Include:
   - a clear description of the issue
   - impact and affected area
   - steps to reproduce
   - proof of concept, logs, or screenshots if available
   - any suggested mitigation

You should receive an acknowledgment within 3 business days. Once validated, we will work on remediation and coordinate disclosure timing with you.
